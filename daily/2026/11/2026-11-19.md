## 1. Vercel UI SDK：Agent-ready 的无头交互行为层

- 官方仓库：https://github.com/vercel-labs/ui
- 核验时 Stars=5,873，Forks=200；创建于 2026-10-26T17:39:27Z。
- `@ui-sdk/core` 提供键盘导航、焦点、选择、弹窗关闭、拖放及 ARIA 语义；面向 React、Vue、Svelte、Solid、Web Components 提供适配器。官方定位为面向 Agent 构建下一代 UI 的行为库。

## 2. Vercel agent-desktop：可访问性树优先的跨平台 Computer Use

- 官方仓库：https://github.com/vercel-labs/agent-desktop
- 核验时 Stars=25,296，Forks=1,891；创建于 2026-02-19T18:00:49Z。
- 通过系统 accessibility tree 返回结构化元素和引用 ID，Agent 可按引用点击/输入并重新检查 UI；提供 CLI、C library、stdio MCP，官方列出 macOS/Windows/Linux 支持。
- 官方 Release v1.3.1 于 2026-11-13T21:02:21Z 发布；本次为首次收录既有项目，并非将旧版发布冒充今日新发布。
