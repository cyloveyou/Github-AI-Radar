## 2. Browser Use 1.0.8：任务评估成本与运行安全细节改进

- 官方 Release：https://github.com/browser-use/browser-use/releases/tag/1.0.8 （2026-11-22 03:30 UTC）。上一期仅提及 1.0.8rc1，**本次核验正式稳定版**。
- Judge 作为运行中的额外一步执行，复用模型提供商缓存上下文，避免为整段轨迹重复付费；结构化 verdict 与 gotchas 保留。实际节约幅度尚无本次独立基准。
- 无 API key 的 SSH/headless 环境增加设备码授权；`bu.type` 不再输出密码字段内容；CDP 附着到已有页面；修复 DeepSeek/Qwen thinking 模式步数上限处无法正确结束的问题。
- 官方 REST 瞬时值：121772 Stars / 13603 Forks；相对 11-22 Snapshot 的差异仅为跨时点计数，不应解释为精确单日增长。
