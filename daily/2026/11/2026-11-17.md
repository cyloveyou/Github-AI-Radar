## 1. Browser Use 1.0.6 — 默认从 bu-fast 改为 BU 4.0

- 官方仓库：https://github.com/browser-use/browser-use
- 官方 Release：https://github.com/browser-use/browser-use/releases/tag/1.0.6 （2026-11-16T00:51:24Z）
- 默认 `Agent(task)` 与 `ChatBrowserUse()` 通过 Browser Use Gateway 使用 `bu-4.0`，而非原来的 `bu-fast`；可指定 `llm='bu-4.0-mini'` 或 `llm='bu-4.0-pro'`。
- **重要兼容性与费用风险**：项目方 Release Notes 明确称不指定 `llm` 时 token 单价为原来的 15 倍。官方给出的输入/输出单价从 $0.12/$0.60 变为 $1.80/$9.00（每百万 token）；短任务示例从 $0.0014 变为 $0.022，约 15.7 倍。**这不等于所有任务实际费用固定上涨 15 倍**，因为 token 消耗和任务行为可能不同。
- 若需保持旧模型与单价，显式传入 `llm='bu-fast'`。模型价格文档：https://docs.browser-use.com/open-source/models
- 首次无密钥运行可打开 Browser Use 登录流程，云浏览器输出实时查看链接；Judge 的 gotchas 限制为本次运行可观测的证据。上述功能均为官方发布声明，尚未独立复现。

## 2. 与历史结论的关系

- 2026-11-13：1.x API/运行模式迁移；2026-11-16：1.0.4 的截图历史修剪和 1.0.5 的自动 Judge。本期 **1.0.6 改动默认模型与价格**，直接影响先前成本基准的可复现性。
- 不应把 1.0.4 在指定基准下的每任务成本下降 52.1% 外推到 1.0.6 默认配置；必须固定 `llm`、模型版本、任务集、缓存状态和 token 计费口径再比较。
