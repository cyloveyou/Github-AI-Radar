- 官方发布：https://github.com/ag-ui-protocol/ag-ui/releases/tag/release%2F2026-11-17 （2026-11-17T16:18:41Z）
- @ag-ui/client 1.0.5 的 compactEvents 保留消息顺序与快照边界，修复并行工具调用互换、快照覆盖增量、STEP 事件顺序被校验拒绝等问题；推理消息增量合并，MessageLookup 优化大型线程重放。

## 2. Cloudflare Agents SDK 适配器：Durable Object 上的 Agent UI 协议

- 新增 @ag-ui/cloudflare-agents 0.1.0，withAGUI(Agent) 将 Cloudflare Durable Object 中的 Agent 通过 HTTP SSE 与 WebSocket 暴露 AG-UI；每个 Durable Object 对应线程，共享 Agent state。
- 新增 run.streamTextOptions()、AGUIRun.request，支持请求上下文、工具、状态、取消信号、认证头及追踪信息的传递。
- AI SDK 工具审批映射为 AG-UI interrupts，可无状态恢复；Durable Object 记录待审批调用，官方声明拒绝不存在的审批与重复执行已批准工具，未独立安全审计。
- 恢复请求若遗漏或错误处理待审批调用，将返回 RUN_ERROR / INVALID_RESUME；服务端状态不会再被客户端过期快照覆盖。
- 兼容性风险：ai peer 变为 ^6 || ^7，WebSocket 帧格式与适配器接口变化，旧接口部分弃用。
