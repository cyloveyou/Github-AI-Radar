## 1. Hermes Agent v0.23.0：统一会话所有权的 Agent Gateway

- 官方仓库：https://github.com/NousResearch/hermes-agent ，MIT；官方 REST 观测 **261,207 Stars**。
- 官方 2026-11-05 发布 v0.23.0：https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.0 。
- 新的单机 Gateway 对 CLI、TUI、Desktop、ACP 编辑器、消息 Bot 和 Cron 的同一会话实施单一所有权，避免多前端并发写同一会话；Webapp 由自托管 Gateway 提供，默认关闭。插件化子 Agent 委派、取消正在执行的 Cron、可设置错过运行时的处理方式，体现 **Session Runtime + Control Plane 合流**。
- 需要验证：跨端并发一致性、认证/公开 URL 配置、Gateway 单点故障及权限隔离。官方大规模性能与插件数量自述不作为独立实证。
