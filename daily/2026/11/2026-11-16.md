## 1. Browser Use 1.0.5 — 浏览器任务自动判定

- 官方仓库：https://github.com/browser-use/browser-use
- 官方发布：https://github.com/browser-use/browser-use/releases/tag/1.0.5（2026-11-14T08:24:22Z）
- GitHub 官方 REST 即时 Stars：121,111，Forks：13,541；不代表自然日增长。
- 1.0.5 在每次运行后使用模型对任务结果进行一次额外判断，返回 `result.judgement`，包括成功、失败原因、提示注入检测、机器人拦截/CAPTCHA 检测与 gotchas；可用 `judge_context` 自定义标准或 `judge=False` 禁用。
- 官方给出 13 次真实运行、每次 3 次判定的小样本测试：遭网站拒绝等问题时，gotchas 检出 15/15（先前 6/15），正常运行中 2/24 被错误标记。**这是项目方自测，不是独立基准或普遍成功率。**

## 2. Browser Use 1.0.4 — 截图上下文修剪与 Prompt Cache

## 3. 技术路线判断与后续验证

- Browser Agent 的竞争焦点从网页操作接口进一步延伸至 **任务结果可判定性、错误归因、上下文缓存与每任务成本**。
