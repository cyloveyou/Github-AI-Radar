## 1. AG-UI：LangGraph/ADK 适配器的安全与恢复语义收紧

- 官方 Release：https://github.com/ag-ui-protocol/ag-ui/releases/tag/release%2F2026-11-21 （2026-11-21 18:04 UTC）。
- `@ag-ui/langgraph@0.0.47` 对客户端传入的 forwardedProps 改为 allowlist，拒绝客户端覆盖 checkpoint/context/config，限制 resume 命令；改变输入时重新开始 run 以重做 gate，修复中断恢复时丢失 pending interrupt。
- `ag_ui_adk@0.14.0` 修复 `/agents/state` 与 `/capabilities` 的依赖授权绕过（GHSA-jhvp-j8pf-5vh5），请求头优先于客户端 state.headers 以防身份伪造；不合法 state 返回 HTTP 422。
- 这些是**实际的权限边界与兼容性变化**，不是单纯版本号更新。使用 AG-UI 的团队应回归测试中断续跑、审批、权限和客户端 forwardedProps 兼容性。官方描述尚未独立安全复现。
- 官方 REST 瞬时值：21,011 Stars / 2,142 Forks。

## 2. Browser Use：长时 MCP 工具调用改为分段取回

- 官方 Release：https://github.com/browser-use/browser-use/releases/tag/1.0.7 （2026-11-20 20:01 UTC）。
- `browser_exec` 运行超过 50 秒时先返回当前输出，底层任务继续运行；再次用空代码调用取回后续结果，绕过部分 MCP 客户端 60 秒超时限制。短任务行为保持不变。
- 1.0.8rc1 是候选版，增加 Judge 使用缓存上下文、SSH/headless 设备码认证等，不把 RC 当成稳定版；见 https://github.com/browser-use/browser-use/releases/tag/1.0.8rc1 。
- 技术意义：长任务从同步等待转向可续取执行，需验证幂等性、超时重试和进程中断恢复。官方 REST：121,681 Stars。

## 3. rust-anything：Agent 驱动的热点代码迁移与差分验证

- 官方仓库：https://github.com/erkamyaman/rust-anything ，创建于 2026-11-16T12:10:36Z；官方 Release v3.1.0：https://github.com/erkamyaman/rust-anything/releases/tag/v3.1.0 （2026-11-21 21:58 UTC）。
- `go --agent claude` 对 TS/JS/Python 工作负载做 profile，选择热点函数，交由 Coding Agent 迁移到 Rust，再经录制用例、差分比较、benchmark 和 gate 决定是否启用；MCP 也提供相应工具。
- v3.1.0 进一步要求 benchmark 不变慢才自动启用，并修复 WASM 跨语言调用造成的性能退化。官方提供一个单次调用比 JS JIT 慢 7.6 倍的反例，说明性能提升并非天然成立。
- 官方 REST 瞬时值：7,399 Stars / 588 Forks；这不等于日增长或真实用户采用。仓库较新、发布密集，技术与 benchmark 尚待独立复核。
