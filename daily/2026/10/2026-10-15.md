## 1. iFixAi：独立 Agent 行为与授权审计

- **官方仓库：** https://github.com/ifixai-ai/iFixAi
- **GitHub REST：** 27,375 Stars / 1,503 Forks；Apache-2.0；创建于 2026-04-27。本期首次收录。
- **正式版本：** https://github.com/ifixai-ai/iFixAi/releases/tag/v4.1.0 ，2026-10-08 06:18:45 UTC。本期关注其新增热度与技术方向，不冒称今日发布。
- **能力：** 面向真实 Agent 端点执行行为探针，检查工具权限、任务遵循、提示注入、数据隔离、失败报告；支持 CLI、CI、Claude Code/Codex 插件与跨客户端 Skill，输出 JSON、Markdown 和分级结果。
- **关键细节：** 默认 10 项检查、完整 60 项；支持独立供应商评判模型。v4.1.0 修复了布尔字符串误判、缺失裁决、截断结果仍计分等可能高估评分的问题。
- **局限：** 项目声称的速度、评分不等于第三方安全认证。README 对默认运行的示例仍涉及数百次被测 Agent 和评判模型调用；需核查费用、误报漏报、评判一致性和适配器覆盖。

## 2. Paperclip v2026.1012.0：外部助手以用户授权身份接入

- **官方仓库：** https://github.com/paperclipai/paperclip
- **GitHub REST：** 102,160 Stars / 17,110 Forks；MIT。
- **正式发布：** https://github.com/paperclipai/paperclip/releases/tag/v2026.1012.0 ，2026-10-12 21:06:53 UTC。该版本此前未被 Radar 收录。
- **核心变化：** 实验性 Assistant Connection (MCP) 允许 Claude Code、Codex、OpenCode 等客户端通过 OAuth 或设备码授权，以已登录用户身份读取、评论和委派任务；支持只读和组织范围限制，默认关闭，要求 HTTPS。
- **授权与恢复：** 不匹配 `scope.allow` 或未知选择器的工具授权现在拒绝执行，不再回退到宽松策略；恢复锁改为 crash-safe SQLite 文件锁，Codex 会话恢复和公司 Skill 的版本化更新得到增强。
- **技术判断：** 从此前已记录的持久工作区与浏览器接管，进一步形成「外部 Harness → 用户委派权限 → MCP 任务流 → Agent Control Plane」。
- **升级边界：** 官方明确要求升级前停止旧服务和 worker；新旧锁协议不可并行写同一实例根目录。需独立测试跨组织访问、授权撤销、写权限限制和异常恢复。

## 3. REA v6.5.0：显式分析范围与分页证据

- **官方仓库：** https://github.com/morluto/rea
- **GitHub REST：** 241,329 Stars / 60,044 Forks；MIT。
- **正式发布：** https://github.com/morluto/rea/releases/tag/rea-agents-6.5.0 ，2026-10-14 12:32:45 UTC。
- **核心变化：** JavaScript 分析可严格限定选中源文件，未选择的文件保留身份与未知覆盖，不擅自扩大范围；跨 bundle 关系保留逐文件来源。二进制、Android、Dart、WASM、网络等结果支持摘要与已留存 Evidence 分页，不必反复执行完整分析。
- **扩展能力：** 离线 SQLite 快照、抓包、记录及 Electron/Rust 元数据检查。官方明确限制了部分功能的操作系统、外部工具版本和测试 fixture 范围，不能推断所有平台均通过验证。
