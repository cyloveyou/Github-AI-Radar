# GitHub AI Radar — 2026-10-20

本期发现五项值得跟踪的新项目：Perplexity SPACE、Headroom、ESP32 iPhone Agent、Magpie、Scout。已与截至 10 月 19 日的日报、项目库、快照及趋势文档去重。

## 核心判断

Agent 基础设施同时向隔离执行、可逆上下文压缩、跨模型网关和真实设备操作演进。项目自报指标不等于独立测评结果。

## 1. Perplexity SPACE：Firecracker Agent Sandbox

- 官方仓库：https://github.com/perplexityai/SPACE ，文档：https://space.docs.perplexity.ai/guide/index.html 。创建于 2026-10-01；REST 核验 **1,682 Stars / 139 Forks**，Apache-2.0。
- 通过 HTTP API 创建和管理 Firecracker 微虚拟机沙箱、执行命令，使用异步 operation ID 和独立数据平面；支持 warm pools、基础快照、E2B 兼容层。
- 10 月 19–20 日主分支新增构建 VM 的 egress policy，缩小网络 guardrail 豁免范围。证据：https://github.com/perplexityai/SPACE/commit/e35f0383be7c 和 https://github.com/perplexityai/SPACE/commit/c17d28284d10 。**主分支提交，不是正式 Release。**
- 区别于已收录的 Substrate：本项目更强调 Firecracker/Kubernetes 的执行生命周期、网络策略和兼容接口。需要独立验证隔离、恢复保真度与启动开销。

## 2. Headroom v0.41.0：上下文压缩进入代理层

- 官方仓库：https://github.com/headroomlabs-ai/headroom 。v0.41.0：https://github.com/headroomlabs-ai/headroom/releases/tag/v0.41.0 （2026-10-14 22:46 UTC）。REST **76,239 Stars / 5,924 Forks**，Apache-2.0；本轮 Trending Daily。
- 提供本地压缩库、模型代理、MCP 和可按需恢复原文的缓存，处理工具输出、日志、代码与 RAG 片段。v0.41.0 新增 Antigravity、OpenCode 2.x 集成和按 Agent 归因的费用统计。
- 10 月 17 日主分支扩展 HTTP/WebSocket 的 OpenAI Responses 请求处理和 Codex WS 统计：https://github.com/headroomlabs-ai/headroom/commit/fbf7bc3278c1 。
- 相较 Context Mode 的工具输出索引，Headroom 更靠近模型请求入口。项目宣称的压缩率与结果不变尚未独立验证；应测试错误信息保留、任务准确率与缓存一致性。

## 3. ESP32 iPhone Agent：实体手机 Computer Use

- 官方仓库：https://github.com/onehumanbeing/esp32-iphone-agent 。创建于 2026-10-11，REST **3,283 Stars / 436 Forks**，MIT。
- 10 月 15 日主分支架构重构：ESP32-S3 负责 AirPlay 接收和 USB HID 输入，同一部 iPhone 上的 App 经 BLE 获取画面、调用视觉模型并规划动作。证据：https://github.com/onehumanbeing/esp32-iphone-agent/commit/f911d841c0f6 和 https://github.com/onehumanbeing/esp32-iphone-agent/commit/80f27a5bbb12 。
- **v0.1.0 是电脑中转的旧架构**；新架构目前在 `main`，不是已发布的 v0.2。README 明确指出首次刷写与构建 App 仍需 Mac/Xcode，只有运行时不需要电脑。
- 项目支持动作回放、轨迹导出和连接中断后的暂停恢复；与网页 Browser Agent 不同，面向真实 iOS 应用。需验证操作成功率、隐私边界和长期稳定性。

## 4. Magpie v0.1.1294：跨 Coding Agent 模型网关

- 官方仓库：https://github.com/yetone/magpie 。发布：https://github.com/yetone/magpie/releases/tag/v0.1.1294 （2026-10-19 18:23 UTC）。REST **16,997 Stars / 1,226 Forks**，MIT。
- 本地网关面向 Claude Code、Codex、Gemini CLI、OpenCode 等宿主，提供跨模型选择、路由和协议转换，支持 OpenAI Chat/Responses、Anthropic Messages 与 Gemini 接口。
- 10 月 19 日 v0.1.1293 支持从任意 Git 仓库安装 Skills；v0.1.1294 可把网关作为 Ollama Server 供 VS Code/Visual Studio 发现模型，并改进路由控制台及 403 错误处理。
- 与 Otari 的供应商显式白名单不同，Magpie 关注跨 Harness 兼容与账户路由。需要验证密钥隔离、工具调用语义及不同服务的使用条款。

## 5. Scout：Browser Agent 的动作、视觉与规划分工

- 官方公开镜像：https://github.com/outcrawlai/scout ；文档：https://outcrawl.ai/docs/scout/overview 。创建于 2026-10-13，REST **951 Stars / 29 Forks**，Apache-2.0。GitHub 仓库声明自动镜像上游代码，目前无 GitHub Release。
- 可选择云端浏览器、本地 Playwright Chromium 或 CDP 会话；`hands`、`eyes`、`brain`、`extract` 分别负责动作、视觉、规划与提取，可配置不同模型。
- 相比单一大模型的浏览器循环，重点是高频操作与低频规划分离。项目自报的网页到达率属于自测，尚未独立复现；云端运行涉及站点授权、隐私和合规边界。
