**Agent 生态的治理边界正从单个 Harness 扩展到网关、终端工作区、跨 Agent 共享状态与企业语义层。** 10 月 27 日 agentgateway 的变化最具工程实质：模型能力/成本目录、MCP 工具输出检查、会话密钥与动态后端网络边界同时升级；tuios 的三项高危修复则说明“只读/列表权限”“Git 仓库配置”“终端输出”都可能成为越权执行入口。相比昨天的 HarnessRouter/Omnigent，本期强调 **网关侧可执行策略与实际漏洞修复证据**，而不是重复收录通用多 Agent UI。

## 1. agentgateway v1.7.0：模型路由、MCP Guardrails 与会话加密成为统一控制面

- **官方仓库：** https://github.com/agentgateway/agentgateway 。GitHub REST **5,683 Stars / 1,003 Forks**，Apache-2.0，2025-03-18 创建；首次纳入 Radar。**v1.7.0 于 2026-10-27 17:18 UTC 发布：** https://github.com/agentgateway/agentgateway/releases/tag/v1.7.0 。
- 模型目录通过 `/v1/models` 与 CEL 暴露上下文窗口、模态和能力；成本按实际服务层级计量，并可按模型/用户查看 token、成本、缓存命中率与延迟。虚拟模型可调用自定义路由服务。
- **重要安全/兼容性变更：** standalone MCP 会话默认使用密钥加密；除 webhook 外的 prompt guard 默认检查 **ToolOutput**；`mcpGuardrails` 支持 CEL 对 MCP 请求/响应实施拒绝或转换；动态后端默认拒绝 loopback/link-local 地址；支持从 Agent 请求头识别会话及 OIDC 浏览器/API 客户端策略。
- **升级注意：** 旧会话密钥可能导致客户端重新建会话；默认 ToolOutput 检查可能增加第三方审核 API 传输内容、误拒绝与费用；动态后端限制可能影响本机测试；`config.session.key: disabled` 和 `allowDynamicLoopback: true` 是显式放宽选项，不能默认建议开启。
- **与昨日对比：** HarnessRouter 主要统一执行接口和工具流，Omnigent 侧重跨 Harness 协作及凭据代理；agentgateway 更接近 LLM/MCP **网络入口的身份、策略、审计和计费数据平面**。需要实测 CEL 策略绕过、跨副本会话撤销和工具输出的提示注入拦截率。

## 2. tuios v0.11.1：三项高危漏洞暴露终端 Agent 控制面的权限边界

- **官方仓库：** https://github.com/Gaurav-Gosain/tuios 。GitHub REST **6,150 Stars / 285 Forks**，MIT，2025-09-06 创建；首次收录。**v0.11.1 于 2026-10-26 13:17 UTC 发布：** https://github.com/Gaurav-Gosain/tuios/releases/tag/v0.11.1 。
- tuios 是具备 Agent 状态感知、跨设备终端会话、worktree 与消息 Inbox 的终端工作区；v0.11.0（10 月 25 日）把多机 Agent 的会话、差异和人工干预整合到 Inbox。
- **官方披露并修复的三项 High 安全公告：**
  1. [GHSA-5q2q-f2hv-wf4h](https://github.com/Gaurav-Gosain/tuios/security/advisories/GHSA-5q2q-f2hv-wf4h)：低权限关联设备可通过 stash/screenshot 等路径读取或覆写本机文件，影响 v0.8.0–v0.11.0。
  2. [GHSA-qcx6-vr32-xr8q](https://github.com/Gaurav-Gosain/tuios/security/advisories/GHSA-qcx6-vr32-xr8q)：仓库可通过 Git hooks/filter/textconv 让 daemon 在 Agent pane/沙箱外执行程序，影响 v0.8.0–v0.11.0。
  3. [GHSA-5cvj-c8rj-c749](https://github.com/Gaurav-Gosain/tuios/security/advisories/GHSA-5cvj-c8rj-c749)：终端输出可影响提示行并诱导命令执行，影响 tuios v0.7.0–v0.11.0 和早期 tuios.dev/vt。
- **操作提醒：** 官方明确需要升级后执行 `tuios restart-server` 才会让修复进入 daemon；这里只记录官方建议，**未在用户机器上安装或执行**。
- **意义：** 终端控制面的“可见会话”“Git 只读操作”不等于安全边界。审计应覆盖跨设备能力、daemon Git 子进程和终端文本/键盘输入的信任隔离；这是比 Stars 更有证据价值的入选理由。
