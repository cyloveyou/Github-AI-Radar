## 1. morluto/rea — Agent-native evidence-first reverse engineering

- **官方 GitHub：** https://github.com/morluto/rea
- **类别：** Coding Agent / MCP / AI Tools / Evidence-first Workflows
- **GitHub REST 本次快照：** 16,976 Stars、1,773 Forks；MIT License；创建于 2026-04-14。
- **动态热度：** GitHub Trending（Daily）本次抓取显示 4,655 stars today。此值是**榜单当时显示口径**，不等于从两次 GitHub REST 快照计算出的日增长；不据此推出持久增速。
- **最新重要发布：** [rea-agents-5.0.0](https://github.com/morluto/rea/releases/tag/rea-agents-5.0.0)，官方标注发布时间 2026-10-07T17:26:47Z；前一版 4.1.0 发布于 2026-10-06。
- **能力与机制：** 通过一个 MCP / CLI 接口将 Ghidra、Hopper、IDA、JavaScript/Electron、网站运行时捕获、Android APK/JADX、固件 Binwalk/Unblob、.NET 元数据和网络抓包等分析能力接入多个 Coding Agent。系统强调结果的来源证据和未知项，而不仅仅生成解释性文本。
- **5.0.0 变化：** Android/Apple 应用清单进入统一图结构；浏览器网络内容、模块导入和 source map 关联证据；JS 模块可读性恢复；Apple 原生 bundle 和 Mach-O 相关分析增强。官方 release notes 有 breaking changes，包括 Android 分析需要完整 JDK 17+。
- **为何是 Radar 级别信号：** 项目不是简单 MCP server 列表，而是把分散的领域工具、目标资产、证据定位与 Agent 推理循环合成可复用专业工作流。相较之前的 BrowserSkill/CUA，本次主题重心是多源静态+动态分析证据，不是单纯界面自动化。
- **边界与风险：** 功能复杂、依赖外部分析器与平台特性；结果应以可复核的原始证据和人工检查为准。仅用于授权软件分析、互操作研究、漏洞防御与合规工作；不将技术描述等同于独立准确率或安全性验证。

## 2. cathrynlavery/diagram-design — 可验证的跨 Harness 图表 Skill（次级信号）

- **官方 GitHub：** https://github.com/cathrynlavery/diagram-design
- **类别：** AI Tools / Coding Agent Skills / Artifact Verification
- **GitHub REST 本次快照：** 45,238 Stars、2,906 Forks；MIT License。
- **动态热度：** GitHub Trending（Daily）本次显示 825 stars today；此为榜单口径，不与 API 快照混作日增量。
- **机制：** 支持 Claude Code、Codex、Copilot、Pi 等宿主，用 HTML+SVG 输出编辑式静态图表，配套导入 Mermaid / draw.io / Excalidraw 和 PNG/SVG 导出，并以图形语义和约束定义避免仅凭模型生成不一致图形。
- **工程级增量：** 官方 README 明列 Label geometry、Sankey conservation、Waterfall running-total、Treemap area、block registry 结构、文档/导出一致性等 CI gates。2026-10-08 最新提交继续修复 verifier 与 export/doctor。
- **为何关注：** 体现 Agent Skill 从模板集合走向**可验证成果物（verifiable artifact）**的路线，特别适合科研流程图、架构图、验证图的生成与复核。它是现有 Agent Skill 趋势的深化，而不是另起一个新的 Agent Runtime 范式。
- **边界：** 宣传的视觉质量主观且无法等同独立测评；生成成果仍需审阅科学内容、数值和标注准确性。

## 综合判断与去重

本期最重要的一条新主线是 **Domain Expert Tools → MCP / Agent Skill → Provenance-rich Evidence → Reproducible Outputs / Validation Gates**。

- REA 重点解决专业软件与 Agent 推理之间的证据流；diagram-design 重点解决生成后可检验的几何和数据约束。两者不属于同一个产品赛道，但共同强化了 Agent 工具链的**可审计性与可验证性**。
- 已有 10-07 自学习 Skill、跨 Agent Memory 和 e2e 测试仍然有效；本期不再把同样的 Skills 叙述当作新发现。
