## 1. PageIndex v0.4.1：无向量 RAG 的 Flash 索引与统一 Agent 工具接口

- 官方仓库：https://github.com/VectifyAI/PageIndex
- 正式发布：https://github.com/VectifyAI/PageIndex/releases/tag/v0.4.1 （2026-10-16 08:15:02 UTC）
- GitHub REST 核验：**39,190 Stars / 3,402 Forks**；MIT 许可证；本期首次跟踪。
- **Flash 构建路径：** 根据 PDF 布局统计与可信书签构造树结构，不需要 LLM 生成树本身；LLM 仍用于节点摘要及可选的树扩展优化。新版针对多语言章节、长财报目录、重复标题与跨页布局进行了修复。
- **本地/云端一致：** 本地与云端客户端共享提交文档、树结构、页面内容、问答和 Agent Tools 的主要接口；本地模式无需 PageIndex API Key、服务器或向量数据库。**本地索引不代表完全离线**，是否调用外部模型取决于所配置的索引/问答模型。
- **Agent 集成：** 支持 `agent_tools()`、`as_openai_tools()`、`as_anthropic_tools()`、`as_claude_mcp()`，并提供 OpenAI Responses / Anthropic Messages 协议通道。
- **价值判断：** 从“向量召回”之外探索**文档结构树 → 可检索节点 → 统一 Agent 工具**的路径，区别于 Context Mode 的工具输出路由和 XERJ 的语料签名。
- **限制：** “比向量索引便宜”是官方自述，尚不能视为跨数据集独立成本/召回率评测。

## 2. Substrate v0.5.0：Sandbox 向有身份、版本和恢复精度的 Actor Runtime 演进

- 官方仓库：https://github.com/agent-substrate/substrate
- 正式发布：https://github.com/agent-substrate/substrate/releases/tag/v0.5.0 （2026-10-14 22:22:40 UTC）
- GitHub REST 核验：**5,316 Stars / 583 Forks**；Apache-2.0 许可证；本期首次跟踪。
- **不兼容变更：** SandboxConfig 支持多个命名版本与默认版本；WorkerPool 新增 sandboxClasses 及可选 SandboxConfig 引用；SnapshotContentScope 被 SnapshotFidelity 梯度及 preferred_fidelity 替代。
- **网络身份与安全边界：** Egress gateway 可以签发/缓存 Actor JWT，出站策略可注入身份；支持 mTLS CONNECT 和 H/2 多路复用；无出站策略时阻断 DNS，系统入口默认拒绝。新版还修复快照存储路径遍历并增加隔离测试。
- **运维可观测：** gVisor/microVM 的 Actor 使用量记录、独立健康探针、恢复与负载基准测试进一步完善。
- **价值判断：** 与已有 `kubernetes-sigs/agent-sandbox` 的 Sandbox CRD 和调度能力互补，Substrate v0.5.0 重点体现 **配置版本化 → 恢复保真度 → Actor 身份 → 网络策略执行**。
- **限制：** 发行说明证明功能合入，不代表已经通过独立的安全绕过、恢复一致性和多租户性能评估；升级包含 Breaking Changes。

- 修复 term/terms 搜索并列排序、text 字段映射、flush 后查询命中归零、whole-file 行号、语料构建拒绝及失败线程降级；新增可选 `xerj code --fuse-symbols`。

- **价值判断：** 上期的签名语料包保障来源/完整性，但无法保证检索结论正确；本次公开失败指标提醒：**语料可信 ≠ 答案可信**。
