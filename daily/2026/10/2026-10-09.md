# GitHub AI Radar — 2026-10-09

> **触发依据：** Paperclip 和 Hindsight 两项此前未入库的 Agent 基础设施项目于 10 月 6–8 日发布了值得独立记录的实质功能升级：前者将持久工作区、Skill 来源、可接管浏览器和多 Harness 调度组合为控制面；后者把事实记忆与团队行为指导分离。昨天已收录的 REA 又在 10 月 8 日发布破坏性 v6.0 并出现可量化的二次爆发。本期不是简单 Star 榜，也不重复 10-07 的可移植 Memory/Skill 主线。

## 1. paperclipai/paperclip — 持久工作区与人机共管执行

- **官方 GitHub：** https://github.com/paperclipai/paperclip
- **重要发布：** [v2026.1005.0](https://github.com/paperclipai/paperclip/releases/tag/v2026.1005.0)，GitHub Release 于 **2026-10-06 16:40 UTC** 发布（release notes 将版本日标为 10 月 5 日）；官方称本版包含 179 commits。
- **GitHub REST 快照：** **98,844 Stars / 16,692 Forks**；MIT。无本仓库同口径前序 snapshot，不计算日增长。
- **实质功能：** 每个 Agent 的 `AGENTS.md` 和支持文件跨任务/会话保留，并发运行只合并各自修改的文件；GitHub Skill 来源经安装快照同步，失败刷新保留最后可用版本；Browser Use Cloud 将浏览器会话嵌入任务页，人类可实时观察、接管并保留会话；MCP 聚合连接器、Slack 双向对话和多 Harness runner 进入统一任务工作流。
- **技术判断：** 核心不是另一个 Coding Agent，而是 **agent-owned workspace + controlled tool access + human takeover + task orchestration**。与 10-06 Kubernetes Sandbox CRD 互补：后者重在环境隔离/调度，Paperclip 重在 Agent 工作组织、状态与可见性。
- **边界：** 以上依据官方 release notes，尚非独立稳定性测试。官方同时列出 @mention 不再自动触发 Agent 运行等 breaking changes，升级前需核查工作流。

## 2. vectorize-io/hindsight — 事实记忆与行为指导分层

- **官方 GitHub：** https://github.com/vectorize-io/hindsight
- **重要发布：** [v0.10.3](https://github.com/vectorize-io/hindsight/releases/tag/v0.10.3)，**2026-10-08 15:47 UTC**。
- **GitHub REST 快照：** **47,284 Stars / 5,970 Forks**；MIT；没有历史同口径 snapshot，不计算增长率。
- **实质功能：** 官方新增「将 memory 视为过去事实记录，让团队单独添加指导」的 Coding Agent 改动；加入 TRAE CN harness 支持，过滤 Codex 非对话内容，修复历史深化任务的锁续约、429 等待，以及 Hermes 内嵌服务启动；同时文档明确 Codex 兼容性限制。
- **技术判断：** 这是对 10-07 可移植 Memory 的语义深化：**episodic evidence（发生过的事）不能直接充当 normative guidance（应该怎样做）**。事实与规则应分别记录、审计、修改和撤回，否则历史片段可能污染 Agent 的长期指令。
- **边界：** 版本变更已由官方核验，但尚无独立对照实验能证明长期准确率、token 成本或跨 Harness 兼容性提升。

- **官方 GitHub：** https://github.com/morluto/rea
- **新版本：** [rea-agents-6.0.0](https://github.com/morluto/rea/releases/tag/rea-agents-6.0.0)，**2026-10-08 09:40 UTC**，距 5.0.0 发布不足 17 小时。
- **历史同口径比较：** Radar 10-08 snapshot（**2026-10-08 05:54 UTC**）为 **16,976 Stars / 1,773 Forks**；本次 REST 为 **26,123 Stars / 2,940 Forks**。两次 API 观测间净增 **9,147 Stars / 1,167 Forks**，约 18 小时，**不是自然日新增量**。
- **实质功能：** v6.0 要求 MCP 文件系统输入使用绝对主机路径（breaking change），新增历史浏览器网络证据、Mach-O dylib、离线 EVM bytecode、Windows PE/Ghidra、ELF、crash/pwndbg、LLDB 调用观察；并收紧未知 MCP 参数输入和大型 JS/ASAR 资源处理。
- **技术判断：** 这是已入库项目的二次爆发和工具契约强化，不能再当作新项目重复收录。对专业 Agent 而言，路径契约、证据来源与资源边界正变得更明确。

## 综合趋势与去重

**Emerging architecture:** `Persistent agent workspace → versioned skills & tools → factual memory vs. explicit guidance → governed live execution → human takeover / audit`。

Paperclip 解决持续执行的组织和人工介入，Hindsight 解决持久上下文的语义边界，REA 解决专业工具调用契约。三者不同赛道，却共同强调**状态可控、证据可追溯、操作可接管**。

已收录的 diagram-design、AutoHarness、Agent Memory Repo、agent-sandbox 等不因普通 Star 变化再次列为新项目。Anthropic knowledge-work-plugins 和 mattpocock/skills 虽仍热门，本轮未发现足以单独触发的重大新版本。
