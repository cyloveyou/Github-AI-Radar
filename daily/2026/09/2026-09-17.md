## Alibaba / Open Code Review
- **Repo:** https://github.com/alibaba/open-code-review
- **Category:** Coding Agent / Code Review
- **Signal:** 当期 GitHub Trending 头部项目，约 +2.7k～2.9k Stars/日。
- **What:** 面向代码审查的 AI 工具。
- **Why watch:** Coding Agent 正从“写代码”扩展到 review、质量保障与团队协作环节。
- **Workflow value:** 可借鉴到科研代码仓库的自动 review、规范检查和潜在错误发现。

## JustVugg / colibri
- **Repo:** https://github.com/JustVugg/colibri
- **Category:** Local Model / MoE Inference
- **Signal:** 当期约 +2.0k Stars/日。
- **What:** 强调纯 C、低依赖以及磁盘流式专家加载的本地 MoE 推理探索。
- **Why watch:** 本地模型的竞争不只在模型权重，也在低资源推理和部署工程。
- **Workflow value:** 对科研工作站离线推理、数据隐私和低依赖部署有参考意义。

## alphaXiv / OpenResearch
- **Repo:** https://github.com/alphaXiv/OpenResearch
- **Category:** Research Agent

- **Workflow value:** 与文献调研、研究问题梳理和证据组织高度相关。
