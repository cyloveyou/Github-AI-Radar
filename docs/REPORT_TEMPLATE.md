# GitHub AI Radar — YYYY-MM-DD

> Trigger: 用一句话说明为什么今天值得生成日报。

## TL;DR

用 2–4 句话总结今天真正发生了什么变化。

## Breakout Projects

### owner/repo

- **Repo:** https://github.com/owner/repo
- **Category:** ...
- **Signal:** 明确写观察时刻、Stars / 增长 / Trending 等可验证信号。
- **What:** 项目解决什么问题。
- **Why watch:** 为什么是现在，为什么不是普通噪声。
- **Workflow value:** 对科研或开发工作流的实际价值。

## Trend Shift

说明这些项目共同指向的技术路线变化；没有可靠证据时不要强行总结趋势。

## Already Tracked, Notable Changes

仅记录已跟踪项目的显著二次爆发、重要发布或方向变化。

## Notes

- Star / Trending 是动态注意力指标，不等于项目质量。
- 对关键数字记录观察日期。
- 不确定的信息明确标注，不把推测写成事实。
