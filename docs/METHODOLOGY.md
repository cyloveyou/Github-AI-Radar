# Methodology

## Scope

重点观察 Agent、Coding Agent、AI 工具、RAG/Context、Browser Agent、本地模型、自动化，以及 Runtime / Sandbox / Memory 等基础设施。

## Trigger

日报不是固定日更。只有出现新项目、新爆发趋势、显著热度变化或明确技术路线信号时触发。

## Evaluation dimensions

1. **Novelty** — 是否提供新的技术/产品路线；
2. **Velocity** — 增长速度是否异常；
3. **Persistence** — 热度是否持续；
4. **Practicality** — 是否能进入真实科研/开发工作流；
5. **Ecosystem signal** — 是否反映更大的 AI 开源生态变化。

## Caveat

GitHub Star 和 Trending 是注意力指标，不等价于软件质量、研究水平或长期价值。判断应结合代码、文档、维护状态和实际用途。
